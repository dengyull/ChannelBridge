# ChannelBridge v1.0.0

首个公开发行版 / First public release.

- Windows x64 多设备环绕声路由，支持 2.0–7.1 的 13 种布局。
- 可视化音箱映射、独立增益与延迟、自动源声道匹配。
- Windows 后台服务、开机恢复、音源音量与静音跟随。
- 单音箱/顺序测试、三次麦克风测量与补偿复测。
- 中文 / English 界面，标题栏语言切换与本机记忆。

Download **ChannelBridge-v1.0.0-win-x64.zip**, extract, and run **ChannelBridge.exe**. The .NET runtime is included. Install VB-CABLE separately from https://vb-audio.com/Cable/.

The archive is built by GitHub Actions from this release tag. `SHA256SUMS.txt` contains its SHA-256 checksum. The executable is unsigned.

Microphone calibration is experimental: drift, reflections and missed signals can cause validation failure. Compensation is saved only when all initial and verification checks pass. This is not hardware clock synchronization. See the README for setup, limitations and service removal.
