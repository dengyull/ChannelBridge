# ChannelBridge v1.1.0

## 中文

- 支持使用输出设备当前 Windows 多声道格式，也可仅发送立体声。可将 7.1 音源分配给原生 5.1 设备和另一对立体声音箱。
- 新增快速映射：按设备报告的音箱位置匹配，确认窗口列出将替换或解除的映射。其他设备上未匹配的位置保留。
- 高级设置新增后台服务进程优先级：低、低于正常、正常（默认）、高于正常、高。应用配置后生效，服务和电脑重启后恢复；不改变 UI 优先级。
- 多声道输出支持独立增益、延迟、静音、测试播放及麦克风补偿。设备声道格式变化时拒绝使用过期映射，避免错位。
- 新预设使用版本 3，支持导入旧版配置。旧软件无法读取新预设，升级前可导出备份。

验证：自动检查覆盖两种 5.1 布局加立体声、声道隔离、重采样、系统音量、优先级保存/重启/错误恢复及中英文界面。Sound Blaster G8 已通过 8 声道和立体声模式的零音量驱动检查；实际音箱位置和声学同步仍需在用户设备上测试。

## English

- Use the output device's current Windows multichannel format or send stereo only. Route a 7.1 source to a native 5.1 device plus a stereo pair.
- Quick mapping matches reported speaker positions and previews replaced or cleared assignments before confirmation. Unmatched positions on other devices remain intact.
- Advanced settings now offers background service process priority: Low, Below normal, Normal (default), Above normal and High. Apply the configuration to activate it; the saved selection survives service and computer restarts. UI priority is unchanged.
- Native outputs support per-channel gain, delay, mute, test playback and microphone compensation. Changed device layouts invalidate stale mappings.
- New presets use schema version 3 and can import older presets. Older software cannot load new presets; export a backup before upgrading if needed.

Validation includes both 5.1 layouts plus stereo, channel isolation, resampling, master volume, priority persistence/restart/failure recovery and both UI languages. Silent driver checks passed on a Sound Blaster G8 in native eight-channel and stereo modes. Physical speaker placement and acoustic synchronization require testing on the user's system.
