# ChannelBridge v1.1.1

## 中文
- 音箱属性新增 Windows 风格设备音量控件：扬声器按钮、蓝色滑块与实时 0–100 数字。
- 直接调整对应输出设备的 Windows 主音量与静音，无需应用配置；同一设备的所有声道共用。
- 支持拖动、点击、鼠标滚轮（每格 2）和键盘操作，并同步 Windows 外部音量变化。
- 原来的单音箱路由静音移至高级设置，仍在应用配置后生效。
- 保留原有增益、延迟、映射和后台路由设置。

下载 Windows x64 ZIP，解压后运行 ChannelBridge.exe。包含 .NET 运行时。此稳定版不包含实验性无线接收功能。

## English
- Add a Windows-style output-device volume control with a speaker button, blue slider and live 0–100 display.
- Change Windows endpoint master volume/mute immediately; all channels on one device share the setting.
- Support dragging, clicking, mouse wheel (2 per notch), keyboard input and external volume changes.
- Move per-speaker routing mute to Advanced settings; it still requires applying the preset.
- Preserve routing, gain, delay and background-service settings.

Download and extract the Windows x64 ZIP, then run ChannelBridge.exe. The .NET runtime is included. Experimental wireless receivers are not included in this stable release.

Packages and verification reports are produced by GitHub Actions. SHA256SUMS.txt verifies the download.
