# ChannelBridge v1.2.0-experimental.3

## 中文
实验性预发布，包含 v1.1.1 的设备系统音量控件，以及实验性无线接收功能。

- Windows 风格音量滑块、实时数字、设备静音按钮，支持鼠标滚轮和键盘。
- A2DP Sink：使用 Windows 接收 API，后台管理选定设备的连接及自动重连；不同蓝牙硬件与服务会话仍需验证。
- AirPlay：由服务管理外部 UxPlayEnhanced 引擎，使用 Windows 原生 DNS-SD 持续公布接收端，重试及网卡地址变化后更新发现信息。
- AirPlay 输出到已应用预设的音源，通常为 CABLE Input。测试电脑已确认 iPhone 可发现并播放音乐。

### 限制
- 无线接收默认关闭。在“高级设置 → 实验性无线接收”配置。
- AirPlay 需要另行下载完整 UxPlayEnhanced 包并选择 uxplay.exe；发行包不包含该引擎，无需手动打开其界面。
- 哔哩哔哩相关 AirPlay 播放兼容性问题仍未解决。
- Chromecast 尚不支持；不提供 AAC/LDAC 编码选择。
- CPU 开销、长期稳定性及更多设备兼容性仍待评估。

## English
Experimental prerelease containing the v1.1.1 Windows endpoint volume controls and optional wireless receivers.

- Add live device volume/mute, wheel and keyboard controls.
- A2DP Sink uses Windows APIs for background connection management and automatic reconnection of selected devices; hardware and service-session compatibility remain experimental.
- AirPlay runs an external UxPlayEnhanced engine and uses persistent Windows DNS-SD registration with refresh on retry and interface-address changes.
- AirPlay outputs to the applied routing source, normally CABLE Input. iPhone discovery and music playback were confirmed on the test PC.

Wireless reception is disabled by default. Download UxPlayEnhanced separately and select its uxplay.exe under Advanced settings → Experimental wireless receivers. The engine is not bundled. Bilibili AirPlay compatibility remains unresolved. Chromecast and AAC/LDAC codec selection are not supported. Long-term stability and CPU overhead still require evaluation.

Download the Windows x64 ZIP and extract it before running ChannelBridge.exe. GitHub Actions builds, tests and packages this release; SHA256SUMS.txt verifies the download.
